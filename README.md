# 🏏 CRICKET KA DUNIYAA

### 🌍 A place where cricket fans can explore the world of cricket!

Love cricket? ❤️🏏  
Then **CRICKET KA DUNIYAA** is for you!

Explore cricket stars from different countries, discover their roles,
jersey numbers, images, player insights and profiles — all in one place. 🌎

🔎 **Search. Explore. Discover. Enjoy the game!** 🏏🔥

---

## 🌟 Features

- 🏏 96 cricket players
- 🌍 8 cricket-playing countries
- 🔎 Search players by name
- 🌎 Filter players by country
- 🎯 Filter players by role
- 🖼️ Player images
- 📋 Player descriptions and insights
- 🔗 Full player profile links
- 🌙 Dark / Light mode
- 📱 Responsive design

## 💡 Why I Built This

As a fan who thinks cricket is an emotion, I wanted to create a simple and interactive place
where cricket lovers can explore players from different countries.

This project helped me practice HTML, CSS and JavaScript while building
something based on one of my biggest interests — cricket! 🏏❤️
